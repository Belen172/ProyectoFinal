# PROYECTO bike

Un sistema integral de gestión para talleres de bicicletas, diseñado para optimizar el registro de clientes, el seguimiento de los servicios y la comunicación directa mediante WhatsApp.

**Enlace a producción:** [proyectobike.com.ar](https://proyectobike.com.ar)

---

## Características Principales

* **Gestión de Servicios:** Seguimiento detallado del estado de cada bicicleta (ingreso, diagnóstico, trabajo realizado y entrega).
* **Notificaciones por WhatsApp:** Envío automático de mensajes a los clientes cuando su bicicleta está lista para retirar, incluyendo el costo final del servicio.
* **Panel de Control:** Interfaz dedicada para administradores/dueños para la gestión eficiente de la carga de trabajo.
* **Buscador de Clientes Avanzado:** Sistema de autocompletado profesional para agilizar la selección y registro de clientes en el taller.
* **Acceso de Clientes:** Portal donde los dueños de las bicicletas pueden consultar el estado de sus reparaciones ingresando su DNI.
* **Historial de Mantenimiento:** Organización inteligente que prioriza las bicicletas con servicios más recientes.

---

## Tecnologías Utilizadas

### Frontend
* **React + Vite:** Para una interfaz de usuario rápida y moderna.
* **Bootstrap:** Implementado para componentes responsivos y estilos profesionales (como el autocompletado de clientes).

### Backend
* **NestJS:** Arquitectura robusta y escalable para la API REST.
* **Base de Datos:** MySQL
